# WebPortfolioZumo

PHP portfolio website with project management and user accounts.

## Configuration

1. Copy `config.example.php` to `config.local.php`.
2. Set the database connection details and SMTP credentials in `config.local.php`.
3. Run the website on a PHP server with PDO MySQL enabled.

`config.local.php` is ignored by Git. Keep it private and copy it separately
when deploying. Existing local credentials are preserved in that file.
